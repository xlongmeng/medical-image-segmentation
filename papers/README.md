# Papers

Use this folder to maintain one note per method or paper family.

Each paper note should answer:

- What problem does it solve?
- What is the main technical idea?
- What assumptions does it make about data, prompts, labels, or modalities?
- What datasets and metrics does it use?
- What is the minimal reproduction target?
- What should be compared against?
- What failure cases should be checked?
